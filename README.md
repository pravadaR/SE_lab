# SE Lab – Student Management App

Pravada Raval · 24BCB052 · Software Engineering Lab

A simple student management web app built with HTML, CSS and JavaScript, used for the SE lab experiments (coding, Git and hosting).

**Live site:** https://pravadar.github.io/SE_lab/

## Files
| File | Purpose |
|---|---|
| `index.html` | Page structure |
| `Design.css` | Styling |
| `Student.js` | `Student` class |
| `Functionality.js` | Add / delete / search / save logic |

## Versions
| Tag | Changes |
|---|---|
| `v1.0` | Add students using the `Student` class |
| `v2.0` | Delete button, student count, Enter key, new UI |
| `v3.0` | Data saved in browser (localStorage), search, README |

## Run locally
Clone the repo and open `index.html` in a browser:
```
git clone https://github.com/pravadaR/SE_lab.git
```
